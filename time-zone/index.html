How to use it

Search a city or country. A code on its own, like IST, CST, MST, or EST, shows only the places that use that code in the usual sense: IST is India, and CST is US, Canada, and Mexico Central. For other places with the same code, add a word: "CST China" shows Shanghai and Beijing, and "IST Israel" shows Jerusalem.

Each city line shows its time zone, the current UTC offset, and the standard code. Codes name the standard time, so Boston shows UTC−04:00 in summer while its code stays EST. Fixed codes like IST (UTC+05:30) never change for daylight saving.
